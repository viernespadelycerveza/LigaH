# La Liga de Campeones

Web responsive para consultar jornadas, resultados y clasificación, con administración local.

## Uso
1. Descomprime el ZIP.
2. Abre `index.html` en el navegador.
3. Administración: contraseña inicial `liga2026`.
4. Los cambios se guardan en `localStorage` del navegador.

## Publicación
Puedes subir todo el contenido a un repositorio de GitHub Pages. Al ser una versión local, los cambios administrativos solo se ven en el navegador donde se hacen. Para sincronización entre dispositivos sería necesario conectar una base de datos.

## Datos incorporados
Se han cargado las jornadas 1 a 18 facilitadas. Las jornadas 1 a 9 incluyen resultados; las 10 a 18 quedan pendientes. No se recibió la jornada 19.
